
If we have 2 different networks, we cannot directly send data to machines in that networks.
So whatever packets we send it takes help of some routing device to reach the destination machine.


We can have multiple network in between our source device and destination device.

Switch :
Switch is a layer 2 device. (Data link layer)
Switch will parse the signal (bits [101010] transferred to it) and figure out what is destination MAC from Frame. So it will route based on MAC Address.

Similar to Router take routing decision on based on IP, Switch takes routing decision based on MAC.
