IP stands for Internet Protocol.
127.0.0.1 is the loopback Ip address.

Representation of IP Address
a.b.c.d where a, b, c, d are integers.

This notation is called as dotted quad notation.

IP Address :

***192.168.1.7***
	 
Where 192 is octet separated by dot.  This above representation is a decimal representation of IP.

We can also represent IP in binary format.

This is binary format for ***192.168.1.7*** :

**11000000.10101000.00000001.00000111**

This will help us to understand why do we need a subnet.  
So we have 8 bits per octet.

So we have 4 octets -> 8 bits * 4 octets -> 32 bits. This is weight of IPv4 address.
